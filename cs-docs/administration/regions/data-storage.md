# Data Storage

## Data Storage

The AWS North America, AWS Europe, AWS Australia, Azure North America, Azure Europe, GCP North America, and GCP Europe regions are completely separate and isolated from each other. Every piece of your [organization](/docs/administration/about-organizations) data resides in your choice of [region](/docs/administration/about-regions). This means that you cannot decide to store some parts of the organization data in one region and the rest in another.

**Note:** Once an organization has been registered/created, you cannot change the organization region.
