# Who can add users to a stack?

Only the [Owner](/docs/headless-cms/types-of-roles#owner), [Admin](/docs/headless-cms/types-of-roles#admin), and users assigned the “[Developer](/docs/headless-cms/types-of-roles#developer)” role can add users to a stack.
