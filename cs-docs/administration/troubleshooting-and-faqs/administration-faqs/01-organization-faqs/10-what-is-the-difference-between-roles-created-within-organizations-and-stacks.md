# What is the difference between roles created within organizations and stacks?

In Contentstack, roles can be assigned at two level: Organization-level roles and Stack-level roles.

While inviting a user to an organization, you can assign Member and Admin roles. These roles define what you can do in the organization. Read more about [organization roles](/docs/administration/about-administration-roles).

When inviting a user to a stack, you can assign Developer, Content Manager or a custom role. These role define what a user can do within the stack. Read more about [stack roles](/docs/headless-cms/about-stack-roles).
