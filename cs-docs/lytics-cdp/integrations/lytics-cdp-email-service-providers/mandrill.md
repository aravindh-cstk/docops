# Mandrill

## Mandrill

## Mandrill

Connecting your Mandrill account gives you the ability to begin collecting email data in real-time. As users open and click on emails sent through Mandrill, Lytics will collect this information and make it available to build segments with.

## Authentication

1.  Navigate to Mandrill in the Integrations section of Lytics. ![mandrill](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/am5eed926a066283c1/292adc95d57678f699364f00/img-0182.png)

1.  Navigate to the **Authorizations** section. ![Authorizations section](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/am4c51fbfd14d78ec6/a06749e7ee154a8c02572028/img-0183.png)

1.  Click the **New authorization** button. ![New authorization](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/amfd18e6dee98674b1/61fe9b43571b5296c279e6af/img-0184.png)

1.  You can create an API Key in the **Settings** tab in Mandrill.
2.  Select _New API Key_. ![api](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/am32c4dde3708675f2/e213e33786469b27eeee43bd/img-0185.png)
3.  Populate the form as below: ![privs](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/am420e0e83edd52f27/d0ea577d12206618053e03b4/img-0186.png)
4.  Copy the API key that Mandrill generates: ![completed](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/amaf94ad6e5b7a87d6/df4ad7055f0e74d38bdd6943/img-0187.png)

1.  Authorize Mandrill by configuring your Mandrill API key ![Mandrill authorization setup](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/am8ba6035ebb248645/fb9da082cdc8acf491e9a803/img-0188.png)

## Import Data from Mandrill into Lytics

1.  [Authorize Lytics with Mandrill](#authentication), if you have not previously done so.

1.  Select **Setup webhooks** from the list of workflows.

1.  This workflow doesn't require any additional configuration. Click **Start setup** and Lytics will begin collecting data in realtime as users open and click through emails sent from Mandrill. ![Start Mandrill setup](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/am12aefe41e45b6e60/61cb7853f41b8050dbf88b04/img-0189.png)
