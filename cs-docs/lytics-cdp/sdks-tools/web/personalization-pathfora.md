# On-site Personalization

## On-site Personalization

## The Pathfora JS SDK

Pathfora JS is a lightweight SDK for displaying personalized modules on your website. Lytics web campaign\\ tools serve as an interface for the Pathfora API, but advanced users may wish to interact directly with\\ Pathfora to achieve deeper customization. You will be able to track any campaign created with Pathfora\\ within Lytics.
