# Preview Entry

## Preview Entry

With Contentstack's [Timeline](/docs/headless-cms/about-timeline) feature, you can now see how changes made to any entry will appear on your website in the future. Follow these steps to preview an entry:

To preview an entry, log in to your [Contentstack account](https://www.contentstack.com/login), and perform the following steps:

1.  Click on the [Entries](/docs/headless-cms/about-entries) icon in the left navigation panel or use the shortcut key “E” (applicable for both Windows and Mac OS users).
2.  Navigate to the entry you want to preview. Click on the “vertical ellipsis” in the **Actions** column and select **Preview**.![Preview Button.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt4fe2197abd4e56b8/667bfe5ec8c1351ac73ca372/Preview_Button.png)

    **Note:** You can preview only the latest versions of your entry.


Depending on the scenario of your entry’s publish status you will see the following modals:

1.  ## Unpublished Entries

    1.  If your entry is not published in any environment and not scheduled for publishing, you need to select the **Environment** and **Locale** to preview your website.
    2.  If your entry is not added to any release or scheduled for publishing, input a tentative **Date** and **Time** to proceed with the preview.![1 - Unpublished Entries.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltd9e2189e91330822/667bfe01c8c135deb73ca362/1_-_Unpublished_Entries.png)
2.  ## Scheduled Publishing

    1.  For entries scheduled to be published, select the **Environment** and **Locale** to preview your website.
    2.  If the entry is scheduled for publishing, you will see a dropdown to select the **Scheduled Publish** option.![2 -  Scheduled Publishing.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltde4f7d6b74414f0d/667bfe013acab019be9e7162/2_-_Scheduled_Publishing.png)
3.  ## Added to an Undeployed Release

    1.  For entries added to a release but not yet deployed, select the **Environment** and **Locale** to preview your website.
    2.  If the entry is part of a release but not deployed, input a tentative **Date** and **Time** for the preview.
    3.  Alternatively, in the **Releases** module, if you try to preview an undeployed release, you will be prompted to input a tentative **Date** and **Time**.![3 - Added to an Undeployed Release.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt223eead8d80b0f9f/66a3878c1a452e816082004a/3_-_Added_to_an_Undeployed_Release.png)
4.  ## Added to a Deployed Release

    1.  For entries added to a deployed release, select the **Environment** and **Locale** to preview your website.
    2.  If the entry is already deployed via a release, you will see a dropdown to select the **Release**.![2 -  Scheduled Publishing or Deployed Release.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltde4f7d6b74414f0d/667bfe013acab019be9e7162/2_-_Scheduled_Publishing.png)

By following these steps, you can ensure that your content updates are accurately reflected on your website before they go live, providing a seamless and consistent user experience.
