# Status

## Status

The Status panel in [Visual Editor](/docs/headless-cms/about-visual-editor) gives you an overview of the current [entry](/docs/headless-cms/about-entries) along with other entries linked or referenced within the web page.

To access the status of a web page using Visual Editor, log in to your [Contentstack account](https://www.contentstack.com/login/) and perform the following steps:

1.  Navigate to your [stack](/docs/headless-cms/about-stack) and select **Visual Experience**.
2.  Click **Editor** in the bottom pill menu.
3.  In the right sidebar, click the **Status** icon. The panel appears, providing details of the selected page.
4.  Expand the relevant sections in the panel to view the following details:
    1.  **Basic Information**: Displays details such as entry ID, content type ID, creator, creation date, last modified by, and last modified date.![Basic Information.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltda3e30889e87228a/69d4dcfed43795229cd04553/Basic_Information.png)
    2.  **Edit Access Request**: Displays pending requests from users who do not have edit access to the entry in its current workflow stage. Approvers can review the request details, including any comments, and choose to **Approve** or **Reject** the request directly from the Status panel.
        
        ![Approve Edit Request.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt369fddc00eacb815/69d4dcffbbaed65cd532168d/Approve_Edit_Request.png)
    3.  **Referenced In**: Lists all entries that reference the selected entry.![Referenced In Status.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltddbf27718d14e029/69d4dcff88e586053897f847/Referenced_In_Status.png)
    4.  **Localization Status**: Shows all languages where the entry is localized and highlights those where it is not.![Localization Status.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt598fb18d8838ceab/69d4dcfe3b53e1880153a96c/Localization_Status.png)
    5.  **Publish Status**: Displays the entry’s publish details, including environment, version, publish date and time, and the user who published it.![Publish Status.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltf095f5057f4bf0a4/69d4dcffb1e57a5b0d052279/Publish_Status.png)
    6.  **Release Status**: Lists all scheduled releases for the selected entry.![Release Status.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt842d212f0f5c632f/69d4dcfe2e26a44596193bc2/Release_Status.png)

Use the Status panel to quickly monitor each entry’s content, localization, and publish status.
