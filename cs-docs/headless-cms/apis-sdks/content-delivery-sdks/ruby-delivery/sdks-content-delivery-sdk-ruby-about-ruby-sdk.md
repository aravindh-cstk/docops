# About Ruby SDK

## About Ruby SDK

_Use Contentstack to power content for your Ruby projects_

Contentstack provides Ruby SDK that Developers can use to develop Ruby applications and power its content from Contentstack. The Contentstack Ruby SDK uses our [Content Delivery APIs](/docs/developers/apis/content-delivery-api) to fetch content from Contentstack and deliver it to your Ruby -based applications.

**Note:** The Contentstack Ruby SDK supports Ruby v2.0 or later.

In order to integrate your Ruby app with Contentstack Ruby SDK, follow the steps mentioned in the [Get Started](/docs/developers/sdks/content-delivery-sdk/ruby/get-started-with-ruby-sdk) section.

You can check out the [sample Ruby apps](/docs/developers/sdks/content-delivery-sdk/ruby/about-ruby-sdk#sample-apps-for-ruby) that Contentstack have developed to see Ruby SDK in action.
