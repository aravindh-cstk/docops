# Bulk Delete Assets

## Bulk Delete Assets

Contentstack’s Bulk Delete Assets feature provides instructions for removing multiple assets from your stack.

To bulk delete assets, log in to your [Contentstack account](https://www.contentstack.com/login), and perform the following steps:

1.  Go to your [stack](/docs/headless-cms/about-stack) and click the “Assets” icon. You can use the shortcut key “A” (for both Windows and Mac OS).
2.  Use the checkboxes to select the assets you want to delete.
3.  After selecting the assets, click the **Delete** option in the floating panel that appears.  
    ![Delete_Icon.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltefcbc76f430582fd/67655584575457248818d1ad/Delete_Icon.png)
4.  A confirmation dialog will appear. Click Delete to move the selected assets to the [Trash](/docs/headless-cms/about-trash).
    
    **Note:** You can select and delete up to **100** **assets** at a time. To delete more than **100** **entries**, repeat the process in batches.
    
    ![Delete_Dialog_Box.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt046a5e12969d7ef4/67655584559f083ad86334ec/Delete_Dialog_Box.png)

**Note:** Deleted assets are moved to the trash and can be restored within **14** **days**. After this period, they will be permanently deleted.
