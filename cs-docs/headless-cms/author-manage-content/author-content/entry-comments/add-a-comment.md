# Add a Comment

## Add a Comment

Adding comments to your Contentstack entries improves team collaboration by enabling you to share feedback, ask questions, or provide instructions directly within the content. Whether it is a simple text field or a complex JSON Rich Text Editor (RTE), comments streamline communication and keep everyone aligned.

To add a comment, log in to your [Contentstack account](https://www.contentstack.com/login/), and perform the following steps:

1.  Go to your [stack](/docs/headless-cms/about-stack) and click the “Entries” icon or use the shortcut key “E” (for both Windows and Mac users).
2.  Open an entry and click the corresponding “Add comment” icon for the field where you want to add a comment.
    
    **Note:** In [Group](/docs/headless-cms/group), [Global](/docs/headless-cms/about-global-field), and [Modular Block](/docs/headless-cms/modular-blocks) fields, comments can only be added to subfields, not the parent field. Additionally, the “Add comment” icon appears only after you have entered some text and saved the entry.
    
3.  Add your comment in the textbox that appears. ![Add comment textbox in Contentstack](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt07275dca83aee889/663e10382ff97d9b347044de/About_Entry_Comment.png)
    
    **Note:** The maximum length of a comment is **500 characters**.
    
4.  Click **Post** to save your comment.

Adding your first comment to a field starts a discussion. You can continue the conversation by adding more comments, resolving them, or managing the discussion. Learn more about [Discussions](/docs/headless-cms/about-discussions).

**Additional Resource:** Refer to our [JSON RTE comments](/docs/headless-cms/json-rte-comments) document for step-by-step instructions on adding comments in the JSON Rich Text Editor.
