# Name Asset Versions

## Name Asset Versions

Assigning custom names to versions can help you better organize and identify specific versions of your assets for improved content management.

By default, Contentstack assigns a version number to each asset (e.g., "Version 1," "Version 2," etc.) . To make versions easier to identify, you can assign custom names, such as "Initial Image for Banner" or "Do Not Edit."

To assign a name to an [asset](/docs/headless-cms/about-assets) version, log in to your [Contentstack account](https://www.contentstack.com/login), and perform the following steps:

1.  Go to your [stack](/docs/headless-cms/about-stack) and click the “Assets” icon.
2.  Navigate to the asset you want to modify.
3.  Click the **version** **dropdown** located in the top-right corner of the page.  
    ![Version_Dropdown.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt8564fee18a589f52/674d6be41621f6d0466e838a/Version_Dropdown.png)
4.  From the dropdown menu, view the list of all asset versions. Click the **Rename** icon next to the asset version you want to rename.  
    ![Rename_Icon.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltd5a781e9e67f8108/674d6c76ef6d5a670e228b95/Rename_Icon.png)
5.  Type the new name for the version in the provided field. Once done, confirm your changes by either clicking the **checkmark** icon or pressing **Enter** on your keyboard.  
    ![Checkmark_the_name.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt47e0b15d7c944ed1/674d6c7627811854355d773d/Checkmark_the_name.png)

**Note:** Custom version names have a maximum limit of **32** **characters**.
