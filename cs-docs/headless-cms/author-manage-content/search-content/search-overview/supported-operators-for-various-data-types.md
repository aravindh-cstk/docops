# Supported Operators for Various Data Types

## Supported Operators for Various Data Types

When working with [Advanced Search](https://www.contentstack.com/docs/headless-cms/advanced-search) in Contentstack, it is essential to understand the different operators available for querying fields across various data types. These operators enable you to filter data efficiently.
