# Request to Add a New Language to Contentstack

## Request to Add a New Language to Contentstack

**Note:** You don’t have to reach out to our support team any more to get a language added to our list of supported languages. You can [add custom languages](/docs/headless-cms/add-a-custom-language) of your choice to your stack in a click.

Contentstack supports [over 200 languages](/docs/headless-cms/supported-languages#list-of-supported-languages). However, if you don’t find the [language](/docs/headless-cms/about-languages) of your choice, you can request us to add it. Here’s how:

1.  ## Request for New Language

    Contact our support team via the in-product chatbox or [email](mailto:support@contentstack.com) us to request for a new language.

2.  ## Provide Language Details

    Our support team will ask you to provide the language and the country in which it is being used. Contentstack supports [country-specific languages](/docs/headless-cms/supported-languages#country-specific-languages) as well as [generic languages](/docs/headless-cms/supported-languages#generic-languages).

3.  ## Contentstack Adds the New Language

    Contentstack's support team forwards the request to add a new language to the engineering team. The engineering team uses [ISO 639-2 Alpha-3 standard](https://www.loc.gov/standards/iso639-2/php/English_list.php) and [ISO 3166-1 Alpha-2 country code](https://datahub.io/core/country-list) to get the corresponding language and country designators for the new language.

    For country-specific languages, the [language code](/docs/headless-cms/supported-languages#language-code-format) comprises two designators (language and country), separated by a hyphen (-). For generic languages, the code contains just one designator (language).

    The engineering team will [add the new language](/docs/headless-cms/add-a-language) to Contentstack's list of supported languages once the corresponding language code is verified and ready for use.

4.  ## Test and Verify the New Language

    Once the new language has been added, we will notify you about it. You can add the new language to your stack and try localizing one of your entries in that specific language.

    **Additional Resource:** Refer our [Add a Language guide](/docs/headless-cms/add-a-language) to learn how to add a language to your [stack](/docs/headless-cms/about-stack).

    For any queries please get in touch with our [support team](mailto:support@contentstack.com).
