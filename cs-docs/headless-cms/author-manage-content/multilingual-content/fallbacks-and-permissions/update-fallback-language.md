# Update Fallback Language

## Update Fallback Language

To update the fallback language of an existing language in your stack, perform the following steps:

1.  Go to your [stack](/docs/headless-cms/about-stack), click to the “Settings” icon on the left navigation panel, and select **Languages**. You can also use the shortcut keys “alt + L” for Windows OS users, and “option + L” for Mac OS users to access languages.
2.  Click on the language you wish to update.![Update_Fallback_Language_1_no_highlight.png](https://images.contentstack.io/v3/assets/blt23180bf2502c7444/bltd9b2811641acdd59/60c07d6df33fd90fa1ed11f8/Update_Fallback_Language_1_no_highlight.png)
3.  In the **Edit Language** window, click on the **Select Fallback Language** dropdown and select a fallback language from the list of available languages.![Update_Fallback_Language_2_no_highlight.png](https://images.contentstack.io/v3/assets/blt23180bf2502c7444/blt8882721c6a2a84d5/60c07d773a3d1a5f519eb548/Update_Fallback_Language_2_no_highlight.png)  

4.  **Save** the changes.

The entries of the set fallback language will act as the parent from which the newly added language entries inherit data from.
