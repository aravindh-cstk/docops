# Set Fallback Language

## Set Fallback Language

Fallback language is the parent language from which any given language inherits data.

When you [add a language](/docs/headless-cms/add-a-language) in the [stack](/docs/headless-cms/about-stack), you are prompted to set the fallback language.

![Set_Fallback_Language_no_highlight.png](https://images.contentstack.io/v3/assets/blt23180bf2502c7444/bltaa7c93838480870e/60c07d21f8aee612d3996a82/Set_Fallback_Language_no_highlight.png)

**Note:** You can only set a language as the fallback language if that language is already added in your stack.

If you want to update the fallback language of an existing language, follow the steps mentioned in the [Update Fallback Language](/docs/headless-cms/update-fallback-language) article.

## API Reference

To set a fallback language for a language via API request, refer to the [Set a fallback language](/docs/developers/apis/content-management-api/languages#set-a-fallback-language) API request.
