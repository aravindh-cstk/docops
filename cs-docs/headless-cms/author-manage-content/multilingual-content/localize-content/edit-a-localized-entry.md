# Edit a Localized Entry

## Edit a Localized Entry

Once you [create an entry](/docs/headless-cms/create-an-entry), you can localize and edit it.

**Note:** Localizing an [entry](/docs/headless-cms/about-entries) does not create a separate item in the main list of entries. Under any given [content type](/docs/headless-cms/about-content-types), you will only see the list of entries in the [master language](/docs/headless-cms/set-the-master-language).

To edit a localized entry, perform the following steps:

1.  Open the entry. By default, the entry will open in the master language.
2.  Navigate to the language-selector located at the top-right corner of the page, and select the language in which you want to localize the entry as shown in the image below. ![Edit_a_Localized_Entry_no_highlight.png](https://images.contentstack.io/v3/assets/blt23180bf2502c7444/blt36855cb8adda28bd/60c0a260971f487708eb23f3/Edit_a_Localized_Entry_no_highlight.png)
3.  Make the necessary changes to the localized entry and click on **Save**.
