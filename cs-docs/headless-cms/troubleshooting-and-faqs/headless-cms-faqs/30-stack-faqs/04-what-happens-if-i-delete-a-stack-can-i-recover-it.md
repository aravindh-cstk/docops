# What happens if I delete a Stack? Can I recover it?

Deleting a stack removes all associated entries, assets, and settings. If you have accidentally deleted a stack, the Contentstack Support team can assist with data restoration. For further information, refer to the [Restore Deleted Content](/docs/headless-cms/restore-deleted-content) document.
