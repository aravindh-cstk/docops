# Can I have separate discussions for entries present in the master locale and other localized versions of the entry?

Yes, discussions can be field-specific for each localized version of an entry. However, the "Comments" feature is not available for unlocalized entries or older versions. For more information, refer to the [About Discussions](https://www.contentstack.com/docs/headless-cms/about-discussions) document.
