# What is the difference between a Global Field and a Group Field?

A [Group](/docs/headless-cms/group/) field is used to group related fields together within a single content type. It helps organize fields logically, especially when dealing with repeated or structured data (e.g., contact information, SEO fields).

A [Global](/docs/headless-cms/global/) field, on the other hand, is a reusable set of fields that you can create once and reference across multiple content types. It’s ideal for maintaining consistency and reducing redundancy in your content model. Updates made to a Global field automatically reflect wherever it is used.
