# Can I nest Global fields within other Global fields?

Yes, Contentstack now allows nesting of Global fields up to **5 levels** deep, including the parent field. This enhancement enables more flexible and complex content modeling. Learn more [Nested Global Fields](/docs/headless-cms/create-a-global-field#using-nested-global-fields).
