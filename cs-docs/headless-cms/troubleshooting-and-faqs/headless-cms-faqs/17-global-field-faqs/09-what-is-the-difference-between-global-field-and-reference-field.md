# What is the difference between Global field and Reference field?

The [Reference](/docs/headless-cms/reference) field lets you link entries from the same or different content types, allowing dynamic relationships between content entries.

The [Global](/docs/headless-cms/about-global-field) field, on the other hand, is a reusable set of predefined fields that can be created once and added to multiple content types. Unlike the Reference field, which pulls existing content, a Global field requires users to input values separately for each entry where it is used.
