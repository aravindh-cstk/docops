# Why do I get the error “Schema.3.uid is a restricted value”?

This error occurs when a field UID uses a reserved keyword. Contentstack [restricts certain keywords](/docs/headless-cms/restricted-keywords-for-uids) from being used as UIDs in content types or entries.
