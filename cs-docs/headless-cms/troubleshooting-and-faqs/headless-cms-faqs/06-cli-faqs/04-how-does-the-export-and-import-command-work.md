# How does the export and import command work?

You can use the [export](/docs/headless-cms/export-content-using-the-cli) and [import](/docs/headless-cms/import-content-using-the-cli) commands to migrate your content from one stack to another. To do this, first you need to use the export command to export the content from the source stack and then use the import command to import it into the destination stack.
