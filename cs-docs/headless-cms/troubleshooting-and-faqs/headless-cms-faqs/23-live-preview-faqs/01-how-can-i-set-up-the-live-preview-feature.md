# How can I set up the Live Preview feature?

To set up [Live Preview](/docs/headless-cms/about-live-preview), you need to first configure the feature for the website for which you want to preview content. Once configured, you can enable Live Preview for the stack that holds your website content through the stack’s “Settings”.

Learn how to [Set up Live Preview for your website](/docs/headless-cms/set-up-live-preview-for-your-website/) and [enable the feature within your stack](/docs/headless-cms/set-up-live-preview-for-your-stack/).
