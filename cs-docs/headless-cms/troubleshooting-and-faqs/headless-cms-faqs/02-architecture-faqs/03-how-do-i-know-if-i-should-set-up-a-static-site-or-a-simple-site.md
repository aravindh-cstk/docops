# How do I know if I should set up a static site or  a simple site?

If the sole purpose of your website is to serve content, and is likely to deliver the same content to all users, you must go for a static website. [Dynamic](/docs/headless-cms/dynamic-website-detailed-architecture) or [simple website](/docs/headless-cms/simple-website-detailed-architecture) architecture, on the other hand, integrates well with other apps, helps you do more with content (such as deliver personalized content, etc.) and enables user interaction.
