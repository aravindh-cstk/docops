# Is there a way to reset my existing Access Token?

Yes. The stack [Owner](/docs/headless-cms/types-of-roles#owner), [Admin](/docs/headless-cms/types-of-roles#admin), or [Developer](/docs/headless-cms/types-of-roles#developer) can reset the Access Token for stacks created before **December 16, 2020.**
