# How can I merge branches?

You can merge the differences in the content type or global field modules of two branches, by either using the [Merging Branches](/docs/developers/apis/content-management-api/#merging-branches) requests in [Content Management API](/docs/developers/apis/content-management-api/#branches) or the [Branch Merge using the CLI.](/docs/headless-cms/compare-and-merge-branches-using-the-cli/#steps-to-merge-branches)
