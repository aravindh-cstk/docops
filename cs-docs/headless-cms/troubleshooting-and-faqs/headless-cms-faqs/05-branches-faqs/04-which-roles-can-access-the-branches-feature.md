# Which Roles can access the branches feature?

Any user with the role “[Owner,](/docs/headless-cms/types-of-roles/#owner)” “[Admin,](/docs/headless-cms/types-of-roles/#admin)” and “[Developer](/docs/headless-cms/types-of-roles/#developer)” will be able to use the branches feature. [Content managers](/docs/headless-cms/types-of-roles/#content-manager) can only work within the branches assigned to them. [Custom roles](/docs/headless-cms/types-of-roles/#custom-role) can access branches as per the permissions assigned to them.
