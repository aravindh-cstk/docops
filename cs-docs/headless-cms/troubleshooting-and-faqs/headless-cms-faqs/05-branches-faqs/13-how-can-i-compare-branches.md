# How can I compare branches?

You can compare two branches to get the differences in the content type or global field modules, by either using the [Comparing Branches](/docs/developers/apis/content-management-api/#branches) requests in [Content Management API](/docs/developers/apis/content-management-api/) or the [Compare Branches using the CLI.](/docs/headless-cms/compare-and-merge-branches-using-the-cli/#steps-to-compare-branches)
