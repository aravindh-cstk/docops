# What is the difference between management tokens and authtokens?

Both [management tokens](/docs/headless-cms/about-management-tokens) and [authtokens](/docs/headless-cms/types-of-tokens#authentication-tokens-auth-tokens) allow read-write access to a [stack](/docs/headless-cms/about-stack), enabling authorized [CMA (Content Management API)](/docs/developers/apis/content-management-api) requests.

-   Authtokens are user-specific and include personal user details with every API request.
-   Management tokens are stack-level tokens not tied to any user, meaning role-specific permissions do not apply.**Additional Resource:** Refer to the [Types of Tokens](/docs/headless-cms/types-of-tokens) document to learn about tokens.
