# Is it necessary to host the JSON RTE plugin on an external server?

No, you can host your plugin in Contentstack by uploading the plugin.system.js file to Assets and using this file URL to add the plugin to a stack. For more information, refer to the [RTE Location](/docs/developer-hub/rte-location) documentation.
