# Can I change the source code for the prebuilt JSON RTE plugins?

Yes, you can clone the [extensions](https://github.com/contentstack/extensions) repository and change the source code for the JSON RTE plugin you want to update. You’ll then need to host this new code and add it to your stack. For more information, refer to our [RTE Location](/docs/developer-hub/rte-location) documentation.
