# Do you have any prebuilt plugins for the JSON Rich Text Editor?

Yes, we have **three** prebuilt plugins, namely Highlight, Info Panel, and Word Count. For more information, refer to our [RTE Location](/docs/developer-hub/rte-location) documentation.
