# Can I use multiple environments within a single stack?

Yes, you can create and manage multiple environments within a single stack. You can also create custom channels for specific needs (e.g., mobile apps, social media) using [Automate](/docs/agent-os/what-is-contentstack-agent-os) or [Webhooks](/docs/headless-cms/about-webhooks).
