# Can workflows be used for automated publishing?

Yes, workflows can be integrated with publish rules for automated publishing. You can set up rules to automatically publish content when it reaches certain stages of the workflow. For more information, refer to the [publish rules](https://www.contentstack.com/docs/headless-cms/about-publish-rules) documentation.
