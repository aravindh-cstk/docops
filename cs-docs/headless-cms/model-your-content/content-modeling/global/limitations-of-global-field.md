# Limitations of Global Field

## Limitations of Global Field

1.  You can add up to **5****00 fields** within a Global field, which aligns with the maximum field limit per content type.
2.  A single content type can include a maximum of **25 Global fields**.
3.  If a Global field is marked as **Multiple**, the total number of instances cannot exceed **100**.
4.  A Global field and a content type cannot share the same name.
5.  You can nest Global fields up to **5 levels**, including the parent field.
6.  Fields within nested Global fields are included in the total field count for the content type.

7.  Labels are not supported in Global fields.
8.  Field visibility rules cannot be applied to Global fields.
9.  Only users with the **Owner**, **Admin**, or **Developer** role can create Global fields.
