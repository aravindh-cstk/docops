# Referenced Content Type

## Referenced Content Type

A [reference](/docs/headless-cms/reference) field allows you to link entries from one content type to entries from another content type. This helps you reuse and manage related content across entries instead of duplicating information.

Use the **Referenced Content Type** property to define which content types users can select entries from while creating or editing entries.

To configure referenced content types, log in to your [Contentstack account](https://www.contentstack.com/login/) and perform the following steps:

1.  Navigate to your [stack](/docs/headless-cms/about-stack) and open the content type where you want to add the reference field.
2.  Add a **Reference** field and click the **Properties** icon.
3.  In the **Referenced Content Type** section, select one or more content types.
4.  Click **Save** or **Save and Close** to apply the changes.

![Referenced_Content_Type.gif](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/amb767f94aac844b5e/b101909c4aebc0d237e317ea/Referenced_Content_Type.gif)

After you configure the referenced content types, content managers can select entries only from the specified content types within the reference field while creating or editing entries.
