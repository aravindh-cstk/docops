# Stack Limitations

## Limitations for Stack

-   You can create only **one stack per minute**.
-   Each stack can have a maximum of **5** [**branches**](/docs/headless-cms/about-branches).
-   Each stack supports only **5** [**environments**](/docs/headless-cms/about-environments).
