# How does caching work with Contentstack?

Contentstack uses [CDN](/docs/headless-cms/what-is-cdn-and-how-it-works) which helps to deliver content and implements caching, wherein the CDN maintains cached copies of the resource that have been accessed via API calls and make them available to users for future requests.
