# How can I import data to Contentstack?

You can import content types as well as entries into your stacks in Contentstack. Our documentation provides in-depth guides and video tutorials on how to import [content types](/docs/headless-cms/import-a-content-type) and [entries](/docs/headless-cms/import-an-entry).
