# Is there a way to search from any module in a stack?

Yes, you can use the [Quick Search](/docs/headless-cms/quick-search) feature to search for [entries](/docs/headless-cms/about-entries) and [assets](/docs/headless-cms/about-assets) from any location within your [stack](/docs/headless-cms/about-stack).
