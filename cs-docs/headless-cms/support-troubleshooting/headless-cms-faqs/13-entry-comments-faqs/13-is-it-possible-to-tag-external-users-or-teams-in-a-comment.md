# Is it possible to tag external users or teams in a comment?

No, only users with access to the content type or entry can be tagged or notified. For more information, refer to the [Mention Users or Roles in a Comment](https://www.contentstack.com/docs/headless-cms/mention-users-or-roles-in-a-comment) document.
