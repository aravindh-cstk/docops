# Which users or roles can use the entry comments feature?

Users or roles with "read" access to a specific content type or entry can access the entry comments feature. For more information, refer to the [Mention Users or Roles in a Comment](https://www.contentstack.com/docs/headless-cms/mention-users-or-roles-in-a-comment) document.
