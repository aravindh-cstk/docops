# Does Contentstack provide the ability to create right-to-left content for languages such as Arabic and Hebrew?

Contentstack supports [writing or adding content from right to left (RTL)](/docs/headless-cms/right-to-left-content-writing-within-the-json-rte) using the JSON Rich Text Editor streamlining the process of content management and editing. However, for other text fields, users can paste Arabic and Hebrew content copied from any source file. Learn how [localization](/docs/headless-cms/about-localization) works.
