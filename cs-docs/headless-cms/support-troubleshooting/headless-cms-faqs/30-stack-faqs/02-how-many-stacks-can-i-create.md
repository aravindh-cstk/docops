# How many Stacks can I create?

You can create only **one stack per minute** as an Organization [Owner](https://www.contentstack.com/docs/headless-cms/types-of-roles#owner) or [Admin](https://www.contentstack.com/docs/headless-cms/types-of-roles#admin). A Contentstack subscription includes at least one Stack. You can purchase additional Stacks as required.
