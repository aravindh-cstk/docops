# Can I add custom validations to the fields of a content type?

Yes. You can add custom validations to “[Single Line Textbox](/docs/headless-cms/single-line-textbox)” and “[Multi Line textbox](/docs/headless-cms/multi-line-textbox)” fields by setting the “[Validations (Regex)](/docs/headless-cms/validation-regex)” property.
