# Can I restrict users from uploading some image types? I want my users to be able to upload only PNG files and not JPEG or any other image type.

Yes, you can set validations on the “[File](/docs/headless-cms/file)” field to restrict users from uploading certain file types. To do this, click the “File” field to open its properties. Then, use the “[Allow file type(s)](/docs/headless-cms/allowed-file-types)” property to allow the upload of specific file types.
