# How do I view the history of changes made to a release?

In [Stack Bulk Task Queue](/docs/headless-cms/stack-bulk-task-queue), you will see the items added to the release. Details such as items removed from release and who locked or unlocked the releases are not visible in the Stack Bulk Task Queue.
