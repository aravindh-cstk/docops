# Can I create more than one rollback release for a deployed release?

Each user who deploys a release gets their own rollback release. Non-admin users can view only the rollback releases they created, while admins can view all rollback releases for the deployed release.

If the same user deploys a release multiple times, rolling back reverts the entries and assets to the state captured during that user’s first deployment.
