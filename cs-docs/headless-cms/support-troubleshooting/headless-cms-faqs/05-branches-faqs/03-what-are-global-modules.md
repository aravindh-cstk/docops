# What are global modules?

Modules such as [Environments](/docs/headless-cms/about-environments), [Webhooks](/docs/headless-cms/about-webhooks), [Workflows](/docs/headless-cms/about-workflows), [Publish Rules](/docs/headless-cms/about-publish-rules), [Users](/docs/headless-cms/about-stack-users), [Roles,](/docs/headless-cms/about-stack-roles) and [Tokens](/docs/headless-cms/types-of-tokens) are globally available. Details for these modules are available across every branch of the stack.

Please refer to our [Global Modules](/docs/headless-cms/global-modules) documentation for more information.
