# Can I add languages specific to a branch?

Yes, you can add languages only to a specific branch of the stack. That language will not be available in other branches of the stack. Please refer to the [Languages](/docs/headless-cms/branch-specific-modules/#languages) section in our [Branch-specific Modules](/docs/headless-cms/branch-specific-modules/) document for more information.
