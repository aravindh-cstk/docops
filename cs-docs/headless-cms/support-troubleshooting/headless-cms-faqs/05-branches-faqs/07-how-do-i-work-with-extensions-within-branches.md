# How do I work with Extensions within branches?

Extensions are specific to a branch. If you add an extension within a branch, it won’t be available across other branches. Please refer to the [Extensions](/docs/headless-cms/branch-specific-modules/#extensions) section in our [Branch-specific Modules](/docs/headless-cms/branch-specific-modules/) document for more information.
