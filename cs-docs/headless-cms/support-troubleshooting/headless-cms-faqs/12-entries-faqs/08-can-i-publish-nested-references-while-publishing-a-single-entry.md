# Can I publish nested references while publishing a single entry?

Yes, you can publish all nested references up to 5 levels of depth by publishing a single parent entry. Check out our [Publish Entries with Nested References](/docs/headless-cms/publish-an-entry/#publish-entries-with-nested-references) documentation to know more.
