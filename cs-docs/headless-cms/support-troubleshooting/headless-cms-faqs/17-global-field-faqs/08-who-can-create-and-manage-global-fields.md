# Who can create and manage Global fields?

Only users with the roles of stack [Owner](/docs/headless-cms/types-of-roles#owner), [Admin](/docs/headless-cms/types-of-roles#admin), or [Developer](/docs/headless-cms/types-of-roles#developer) have the permissions to create and manage Global fields.
