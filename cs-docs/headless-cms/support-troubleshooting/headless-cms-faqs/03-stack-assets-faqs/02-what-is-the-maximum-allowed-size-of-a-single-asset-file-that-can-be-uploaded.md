# What is the maximum allowed size of a single asset (file) that can be uploaded?

The maximum allowed size for a single asset file is **700 MB**. Additionally, you can define custom file size limits (both maximum and minimum) using the [File Size Limit](/docs/administration/validations#file-size-limit) validation rule.
