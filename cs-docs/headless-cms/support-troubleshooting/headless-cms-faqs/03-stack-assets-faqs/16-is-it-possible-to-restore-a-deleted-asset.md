# Is it possible to restore a deleted asset?

[Trash](/docs/headless-cms/about-trash) maintains a backup of all deleted assets for up to **14 days** from the date of deletion. You can [restore](/docs/headless-cms/restore-a-deleted-asset) deleted assets before they are permanently deleted.
