# Does Access Token deprecation affect all stacks?

No. The deprecation only applies to stacks created after **December 16, 2020**. [Stacks](/docs/headless-cms/about-stack) created before this date still support Access Tokens. However, using Delivery and Management Tokens is strongly recommended.
