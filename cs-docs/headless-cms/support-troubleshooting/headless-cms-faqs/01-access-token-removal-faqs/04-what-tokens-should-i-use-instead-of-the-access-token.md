# What tokens should I use instead of the Access Token?

-   Use Delivery Tokens to fetch environment-specific published content such as [assets](/docs/headless-cms/about-assets) and [entries](/docs/headless-cms/about-entries) via the Content Delivery API.
-   Use Management Tokens or Authtokens to fetch unpublished or draft content via the Content Management API.
