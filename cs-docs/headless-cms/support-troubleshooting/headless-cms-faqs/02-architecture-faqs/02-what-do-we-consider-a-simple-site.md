# What do we consider a simple site?

A simple site is a website that has a few pages and limited third-party integration. An example of a [simple website](/docs/headless-cms/simple-website-detailed-architecture) could be a marketing site of an enterprise, which uses basic integration services such as website search, site analytics, and so on.
