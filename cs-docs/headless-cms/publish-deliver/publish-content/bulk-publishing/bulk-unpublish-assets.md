# Bulk Unpublish Assets

## Bulk Unpublish Assets

Contentstack’s Bulk Unpublish Assets feature helps to unpublish multiple assets. It covers the process of selecting assets, specifying environments and languages, and scheduling unpublishing actions.

To bulk unpublish assets, log in to your [Contentstack account](https://www.contentstack.com/login), and perform the following steps:

1.  Go to your [stack](/docs/headless-cms/about-stack) and click the “Assets” icon. You can also use the shortcut key “A” (for both Windows and Mac OS).
2.  Use the checkboxes to select the assets you want to unpublish.
3.  After selecting the assets, click the **Unpublish** option in the floating panel that appears.![Unpublish_Icon.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt5c36b4787940276c/676554c9775da70e801f2995/Unpublish_Icon.png)
4.  In the **Unpublish** **Assets** modal:
    
    1.  **Select Environment(s):** Select the environment(s) from which the assets must be unpublished.
    2.  **Select Language(s):** Select the locale(s) in which you want the assets to be unpublished. If a localized asset exists, it will be selected automatically.
    
    ![Unpublish_Button.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt5f41b61f173336d1/676554c8e4bfd3cfddac5253/Unpublish_Button.png)
5.  Click **Unpublish** to unpublish the selected assets.

**Note:** You can unpublish up to **10** **assets** simultaneously in **10** **languages** across **10** **environments**.
