# How do I delete an existing Voice Profile?

To delete an existing Voice Profile from a Brand Kit, go to the Voice Profiles dashboard. Click the **Delete** option under the **Actions** tab to permanently delete the Voice Profile. For more information, refer to the [Delete a Voice Profile](/docs/brand-kit/delete-a-voice-profile) documentation.
