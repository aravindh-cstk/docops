# How do I set the Communication Style Mixer to create a Voice Profile?

To create a Voice Profile in Contentstack's Brand Kit, adjust the Communication Style Mixer settings, including the Formality Level, Tone of Voice, Humor Level, and Language Complexity Level. These settings help define how your brand's AI-generated content should sound and engage with the audience. For more details, refer to the [Create a Voice Profile](/docs/brand-kit/create-a-voice-profile) documentation.
