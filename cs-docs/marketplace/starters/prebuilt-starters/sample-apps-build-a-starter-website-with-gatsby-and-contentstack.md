# Gatsby Starter

<p class="warning"><strong>Note</strong> Contentstack no longer supports Starters. We recommend using <a href="/docs/headless-cms/next" target="_self">Kickstarts</a> which are pre-built, minimal code templates designed to help you quickly integrate your project with Contentstack.</p><p>Gatsby is a framework to build static websites. This Gatsby starter website guide will help you to build a website using Gatsby and power its content from Contentstack.</p><p>The <a rel="noreferrer" href="https://www.gatsbyjs.com/plugins/gatsby-source-contentstack/" target="_blank">contentstack-gatsby</a> plugin will ease the process of storing and delivering content to the Gatsby starter website from Contentstack.</p>
