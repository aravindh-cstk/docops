# Next.js Starter

<p class="warning"><strong>Note</strong> Contentstack no longer supports Starters. We recommend using <a href="/docs/headless-cms/next" target="_self">Kickstarts</a> which are pre-built, minimal code templates designed to help you quickly integrate your project with Contentstack.</p><p>Next.js is a minimalistic framework for server-rendered React applications.</p><p>This guide will help you create a starter website built on top of Next.js with minimal steps. It uses Contentstack’s Node.js SDK to store and deliver the website content from Contentstack.</p><p>Server Side Rendering (SSR) generates website pages at runtime on the server. With SSR, users are served the latest content on their websites.</p>
