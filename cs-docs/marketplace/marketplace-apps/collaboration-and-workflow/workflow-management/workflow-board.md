# Workflow Board App Installation Guide

## Workflow Board App Installation Guide

The Workflow Board is a [Full Page Location](/docs/developer-hub/full-page-location/) app, which displays the workflow stages and tasks in a Kanban format. You can view the list of workflows along with the workflow stages and workflow tasks for content types within your Contentstack environment. You can drag and drop the tasks from one workflow stage to another and update the required details. Also, the app enables you to search for workflows and entries in the Workflow Board app. You can apply various filters to sort the workflow task cards.

Contentstack Marketplace lets you integrate the Workflow Board app directly into your headless CMS. You can easily use this app to view the workflows of your stack. It displays all the workflow stages and tasks on the Workflow Board app in a Kanban view.

## Prerequisites

-   [Contentstack account](https://www.contentstack.com/login/)
-   Access to the Contentstack Organization/Stack as the Owner/Admin

Let's follow this step-by-step guide to install and configure the Workflow Board app within your stack.

## Steps for Execution

1.  [Install and Configure the Workflow Board app in Contentstack Marketplace](#install-and-configure-the-workflow-board-app-in-contentstack-marketplace)  

2.  [Use Workflow Board within your Stack](#use-workflow-board-within-your-stack)

1.  ## Install and Configure the Workflow Board app in Contentstack Marketplace

    Follow the steps to install the application in Contentstack.

    1.  Log in to your [Contentstack account](https://www.contentstack.com/login/).
    2.  Navigate to the “App Switcher” icon in the top-right corner and click **Marketplace**.  

        ![Contentstack-App-Switcher-Marketplace](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt47c618781b542b64/68ee96ad6bfd93c9913fee8a/Contentstack-App-Switcher-Marketplace.png)  

    3.  Click **Apps** from the left panel.
    4.  Within the Marketplace, you can see all the available apps. Hover over the **Workflow Board** app and click **Install App**.  

        ![Marketplace-Workflow-board.png](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt588d40af9a0741d5/69eeaaa955f8965fb0f3da99/Marketplace-Workflow-board.png)  

    5.  In the popup window, select the stack where you want to install the Workflow Board app and click the **Install** button.  
        ![Workflow-Board-Install-App](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltc3a9c87e9f4df128/64b927131add4d1fbbfbb337/Workflow-Board-Install-App.png)  

    6.  On the **UI Locations** tab, you can see the predefined app locations. You can use the toggle button corresponding to each UI location to enable or disable it based on your requirements. ![Workflow-Board-UI-Locations](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt66f68c0c39142fa9/65b8321a24ea49ddacde5f00/Workflow-Board-UI-Locations.png)
    7.  **Note:** No additional configuration is required to use the Workflow Board app.

2.  ## Use Workflow Board within your Stack

    To use the Workflow Board application in your stack, follow the steps given below:

    1.  Log in to your [Contentstack account](https://www.contentstack.com/login/).
    2.  In the left-hand side primary navigation, click **Settings** of your stack, navigate to **Workflows**, and then click **\+ New Workflow** to create a new workflow.  
        ![Workflow_Board_Create_New_Workflow](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt791584277370bd22/6458de5d51a7d778535555d8/Workflow-Board-Create-New-Workflow.png)
    3.  Enter the **Workflow Name** and **Description**, select the **Scope**, add the **Workflow Stages** and **Workflow Superuser(s)**, **Enable** the workflow, and click the **Save** button.  
        ![Workflow_Board_Save_New_Workflow](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt3c444d111156ea59/6458de7c7a411038a223285e/Workflow-Board-Save-New-Workflow.png)  
        This creates your new workflow.  
        ![Workflow_Board_Created_Sample_Workflow](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt7b3f6605f221b64b/6458de5d54b49c394e5166bd/Workflow-Board-Created-Sample-Workflow.png)

        **Note:** You can also set the [Publish Rules](/docs/headless-cms/about-publish-rules/) for the workflow stages.

    4.  Now, click **Entries** in the left navigation panel, open the entry that belongs to the content type added to the workflow, and then click the **Workflow Details** icon in the right navigation panel of your entry.  
        ![Workflow_Board_Workflow_Details](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt4c1eac098927fddf/6458decaf6d4ab4694deeeb6/Workflow-Board-Workflow-Details.png)
    5.  Set the workflow stage of an entry and assign the workflow task to the user or role, add comments, and then click **Save**.  
        ![Workflow_Board_Set_Stage](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt6d978ff48d107d23/6458de7dcb09345e47b97abe/Workflow-Board-Set-Stage.png)  
        You can track the workflow tasks assigned by clicking **Tasks** in the left-hand side primary navigation panel.  
        ![Workflow_Board_Tasks](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt93aaee93a9bd7392/6458de7d5656d54f815d6f82/Workflow-Board-Tasks.png)

        **Additional Resource:** For more information about [Workflows](/docs/headless-cms/about-workflows/), [Workflow Stages](/docs/headless-cms/about-workflow-stages/), [Workflow Tasks](/docs/headless-cms/about-workflow-tasks/), and [Publish Rules](/docs/headless-cms/about-publish-rules/), please refer to the [Set up Workflows and Publish Rules](/docs/headless-cms/about-workflows/) documentation.


    ### Workflow Board App

    1.  Now, go to the stack dashboard. In the left-hand side primary navigation, you will find the **Workflow Board** app icon (as shown below).  
        ![Workflow_Board_Full_Page_App_Icon](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt664aae5b2716f903/6458e9fc24243711ffb5160f/Workflow-Board-Full-Page-App-Icon.png)

        **Note:** Workflow Board is a Full Page Location app. For more information, refer to the [Full Page Location](/docs/developer-hub/full-page-location/) documentation.

    2.  Click the app icon to view the Workflow Board app within your CMS.  
        ![Workflow_Board_Full_Page_Location_App](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blte0318687809e86f6/6458de6f4c5d3a07d30beccc/Workflow-Board-Full-Page-Location-App.png)
    3.  You first need to authorize the app by providing access to your stack. Click the **Authorize** button to start using the app.  
        ![Workflow_Board_Authorize_App](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt7816b848963641a6/645cee51cae4f13fa165bf1a/Workflow-Board-Authorize-App.png)  

    4.  In the popup window, click the **Authorize** button again to authenticate the Workflow Board app.  
        ![Workflow_Board_Authorize_Stack](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt89ecdde50bde1800/6458de5d6c8b04210a300366/Workflow-Board-Authorize-Stack.png)  
        The Workflow Board app will show a list of all workflows in the left panel and all the workflow stages and tasks (entries) on the right side of the board.  
        ![Workflow_Board_App](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt780c303e4f16f115/645cee3f0a3fbbd3e6ee2760/Workflow-Board-App.png)  

        **Note:** The first created workflow is visible on top of the list. By default, the Workflow Board app displays the workflow stages and entries for the first created workflow.

        **Tip:** If Workflows are already created and not visible on screen, please contact the Super Admin to remove the **Workflow Old API** plan from your organization.

    5.  Click the **Edit Workflow** icon to edit the workflow in the Contentstack Workflow editor.  
        ![Workflow_Board_Edit_Workflow](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blte9e32dba7c9378a6/6458de5e0de513497797455a/Workflow-Board-Edit-Workflow.png)  
        Also, you can search for any workflow using the search bar.  
        ![Workflow_Board_Search_Workflow](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt09ab7961f315b69d/6458de7cc49bb3399f5dfef0/Workflow-Board-Search-Workflow.png)
    6.  Click the **Collapse** icon to hide the list of workflows.  
        ![Workflow_Board_Collapse_Sidebar](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt7d844ad220cb1527/645cee65d4a7920fc13dc510/Workflow-Board-Collapse-Sidebar.png)  

    7.  Click the **Expand** icon to show the list of workflows if the sidebar is collapsed.  
        ![Workflow_Board_Expand_Sidebar](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt37361882052e8954/645ceea0bb50542f860fdcb4/Workflow-Board-Expand-Sidebar.png)  

        **Note:** By default, the sidebar for the list of workflows is always visible.

    8.  To view the workflow stages and tasks (entries), click the **workflow name** in the left panel of the Workflow Board app.  
        ![Workflow_Board_Select_Workflow](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt6f627061c77c3ed3/645ceef9cae4f1906765bf1e/Workflow-Board-Select-Workflow.png)  

        **Note:** On page reload or page navigation, the app shows the workflow where it was before refreshing the landing page.

    9.  ### Workflow Stages

    The Workflow Board app displays the workflow stages and the total number of entries that belong to the stage on the top of the board. You can scroll right to view all the workflow stages.  
    11.  ![Workflow_Board_Workflow_Stages](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltcfc2d39ef1b63a07/645ceeec61e04484d714e543/Workflow-Board-Workflow-Stages.png)

    13.  ### Workflow Tasks

    The Workflow task (or entry) preview card shows all the associated details. You can view the Entry title, Content type name, Release name (if any), Locale, and the number of assignees. You can use the vertical scroll bar to see all the workflow tasks.  
    15.  ![Workflow_Board_Workflow_Tasks](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt4ac917531d99beca/645ceed4cae4f10e9065bf1c/Workflow-Board-Workflow-Tasks.png)

    If a task is not assigned to any user or role, the card shows the **Unassigned** state.  
    19.  ![Workflow_Board_Permissions_Unassigned](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltac7a64a63ecb1e64/6458de7cd898ec138433b5b4/Workflow-Board-Permissions-Unassigned.png)

    If a task is assigned to a user, the card shows the total number of assignees in the **User(s)** category. Hover over the **User(s)** category to view all the assigned users' names.  
    24.  ![Workflow_Board_Permissions_Users](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltdd3b52286e9c0092/6458de7c2887da2451857f00/Workflow-Board-Permissions-Users.png)

    If a task is assigned to a role, the card shows the total number of roles assigned to the entry in the **Role(s)** category. Hover over the **Role(s)** category to view all the permitted roles.  
    29.  ![Workflow_Board_Permissions_Roles](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt2334d963ea187fd6/6458de6f0de5132af197455e/Workflow-Board-Permissions-Roles.png)
    30.  Drag and drop a workflow task card to move it from one workflow stage to another.  
         ![Workflow_Board_Drag_Task](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt83437dca749cff77/645cee7760b10c005baf90d4/Workflow-Board-Drag-Task.png)  
         When you drop a task in another stage, a popup appears to update the status of the workflow task. Set the required details, and click the **Update** button.  
         ![Workflow_Board_Update_Stage](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt7caff6e75f50886c/6458de7d5c83193accd40e08/Workflow-Board-Update-Stage.png)  
         The task, now, is visible in another stage.  
         ![Workflow_Board_Drop_Task](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt568447bb8f9ade99/645cee91a64c09472b530e4f/Workflow-Board-Drop-Task.png)  

         **Note:** If the workflow task is restricted from any workflow stage, you can see a message when you drag the card to that stage.

    31.  ### Workflow Board Filters

    32.  The Workflow Board app lets you apply filters based on the entries.

         -   **Search an Entry**: You can search an entry by typing the entry title in the search bar.  
             ![Workflow_Board_Search_Entry](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt67b17e04088ab015/6458de7c51a7d76e1d5555e4/Workflow-Board-Search-Entry.png)  
             Also, you can view the total number of entries in a workflow on the Workflow Board app. Click the **Reload** icon to update the number if any entry is added or deleted.  
             ![Workflow_Board_Reload_To-Update_Entries_Count](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt20fa98b0b1ad21b2/6458de7c0de51381bb974562/Workflow-Board-Reload-To-Update-Entries-Count.png)
         -   **Content Type Filter**: You can view the workflow tasks (entries) based on the selected **Content Type(s)**. By default, the **All Content Types** option is selected.  
             ![Workflow_Board_Filter_Content_Type](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltb11290401151b7a6/6458de6fd66b1b1ba5a60631/Workflow-Board-Filter-Content-Type.png)
         -   **Sort By Filter**: You can shuffle and sort the tasks (entries) according to the available sorting options.  
             ![Workflow_Board_Filter_Sort_By](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltee17b224aa913e47/645b60429d323aecf35b69a3/Workflow-Board-Filter-Sort-By.png)  
             By default, the **Modified At: Newest** option is selected. It enables you to view the entries arranged in their recently modified order.  
             ![Workflow_Board_Filter_Modified_At_Newest](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltebb404d14146e170/645cef4ef55683eea4dffa49/Workflow-Board-Filter-Modified-At-Newest.png)  
             Select the **Title (ASC)** option from the **Sort By** dropdown to view the entries arranged in the ascending alphabetical order of the entry titles.  
             ![Workflow_Board_Filter_Title_Ascending_Order](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/bltcc1d61c8a24b07ba/645cef1ee0f3410afd57a892/Workflow-Board-Filter-Title-Ascending-Order.png)  
             Select the **Title (DESC)** option from the **Sort By** dropdown to view the entries arranged in descending alphabetical order of the entry titles.  
             ![Workflow_Board_Filter_Title_Descending_Order](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt7335f3315de27cd2/645cef1161e0444a2a14e545/Workflow-Board-Filter-Title-Descending-Order.png)  
             Select the **Modified At: Oldest** option from the **Sort By** dropdown to view the entries arranged in the order as per the oldest modified entry.  
             ![Workflow_Board_Filter_Modified_At_Oldest](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt0ac2bd1e40e3731c/645cef3230b8396131fd4a9c/Workflow-Board-Filter-Modified-At-Oldest.png)  
             Select the **Created At: Newest** option from the **Sort By** dropdown to view the entries arranged in their recently created order.  
             ![Workflow_Board_Filter_Created_At_Newest](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt6aa50ff7e3ead7d2/645cef72151406d864f2fabc/Workflow-Board-Filter-Created-At-Newest.png)  
             Select the **Created At: Oldest** option from the **Sort By** dropdown to view the entries arranged in the order as per the oldest created entry.  
             ![Workflow_Board_Filter_Created_At_Oldest](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt243e61c0a2a4436c/645cef95ce0b91172ae807b4/Workflow-Board-Filter-Created-At-Oldest.png)  

         -   **View Type Filter**: You can preview the workflow task cards in a **Comfortable** or **Compact** view.  
             ![Workflow_Board_Filter_View_Type](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt9cb1975429b303d6/645b60421ce8dfa3dfaadacd/Workflow-Board-Filter-View-Type.png)  
             By default, the **Comfortable** option is selected.  
             ![Workflow_Board_Filter_Comfortable_View](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt2b7474df7af1ef13/645ceeb00227877d442d721a/Workflow-Board-Filter-Comfortable-View.png)  
             Select the **Compact** option from the **View Type** dropdown to view the workflow task cards in compact view.  
             ![Workflow_Board_Filter_Compact_View](https://images.contentstack.io/v3/assets/blt2d43f51baca745a8/blt7bb6a6c6f2c5b4e1/645ceec1a64c097d84530e51/Workflow-Board-Filter-Compact-View.png)
