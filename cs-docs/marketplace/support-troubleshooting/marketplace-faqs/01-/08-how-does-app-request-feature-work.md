# How does app request feature work?

Non Organization/Stack Owners/Admins can request for Marketplace app installation in the stack of their choice. The request is sent to the admins. Admins can view these requests in the **Marketplace > Manage > App Requests** section and then decide whether to install the app or reject the request.
