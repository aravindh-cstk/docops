# How are apps different from extensions?

[Marketplace apps](/marketplace) are enhanced versions of extensions. Using extensions is currently a manual, and developer-centric experience. Whereas [Marketplace apps](/marketplace) are quite easy to install and can be used by any audience regardless of your expertise. Apps also allow you to overcome few limitations of extensions.
