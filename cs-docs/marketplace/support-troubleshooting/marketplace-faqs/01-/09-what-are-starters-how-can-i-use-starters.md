# What are Starters? How can I use starters?

Contentstack Marketplace offers easy, quick installation and hosting of starter apps. [Starters in Marketplace](/docs/marketplace/installing-a-starter) are designed to help beginners learn how to build websites using Contentstack. Navigate to the Contentstack Marketplace page, then go to the Starters section to install the app of your choice.
