# How does an admin grant Polaris access to a member?

1.  Go to **Administration** > **Roles**
2.  Click **Create Custom Role** and give it a name (e.g., "Polaris Viewer")
3.  Enable **Read** access under the **Polaris** section and saveGo to the user's profile, assign the new Custom Role, and save The user will see the Polaris icon after refreshing their browser.
