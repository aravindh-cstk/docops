# Polaris Prompts

## Polaris Prompts

**Note:** For access, please talk to our [Support](mailto:support@contentstack.com) team.

Prompt engineering is the practice of writing clear, purposeful instructions for **Contentstack Polaris** so it can accurately understand your intent and deliver the right outcomes. Well-designed prompts help you get more precise results when managing content, automating workflows, enriching entries, or generating insights across your Contentstack stack.

## Tips for Effective Polaris Prompts

Here are quick reminders to boost prompt quality:

-   Break complex tasks into smaller pieces.
-   Mention relevant tools or APIs if needed.
-   Ask for explanations, not just output.

## Example Prompts for Content Operations

Below are customized examples for common workflows you can perform using the Polaris Chat inside Contentstack:

### Entry operations

**Explanation:** These prompts cover creation, improvement, translation, publication, and release planning, key content lifecycle operations in CMS workflows.

**Examples:**

-   _Draft a new blog entry about the role of AI in content management._
-   _Improve the tone and clarity of this blog entry to make it more engaging._
-   _Translate this blog entry into French, keeping industry terminology accurate._
-   _Publish this entry to the live environment._
-   _Tag this entry for the next release cycle and add it to the upcoming release._
-   _Add a comment on the Body field asking for a link to the content modeling guide, and mention @Jane Doe._
-   _Read the open comments on this entry, apply the feedback, then resolve the comments you addressed._

### Asset operations

**Explanation:** Good metadata improves search and accessibility; alt text should describe content clearly for both users and search engines.

**Examples:**

-   _Update metadata for this image to include SEO-friendly tags._
-   _Suggest three alternative alt text options for this image based on context._

### Visual Editor operations

**Explanation:** These prompts support marketing operations, from page design to content refinement.

**Examples:**

-   _Create a landing page layout for an upcoming product Launch._
-   _Shorten and sharpen the content on this page to improve readability._

### Release operations

**Explanation:** These prompts manage a release from creation to rollback.

**Examples:**

-   _Create a release called Spring Launch, add both blog entries to it, and deploy it to the staging environment._
-   _Roll back the Spring Launch release on staging._

### Stack setup

**Explanation:** These prompts set up stack resources without leaving the conversation.

**Examples:**

-   _Create an environment called preview without a base URL._
-   _Connect the Spring Campaign Personalize project to this stack._
-   _Create two blog entries and generate their URLs from the content type's URL pattern._

### User and access management

**Explanation:** These prompts manage access to a stack. Polaris applies the same permissions you have in the UI.

**Examples:**

-   _Who has access to this stack? Include pending invitations._
-   _Invite name@example.com to this stack as a Developer._
-   _Change name@example.com's role on this stack to Content Manager._
-   _Resend the invitation to name@example.com._

### File exports

**Explanation:** Export prompts turn content into a file you can download.

**Examples:**

-   _Export this entry as a Markdown file._
-   _Export all Blog Post entries as a JSON file._
-   _Create a PDF of this entry._

### User guidance

**Explanation:** These questions extract instructional help and architectural guidance. Polaris answers product questions from the Contentstack documentation and links to the relevant guide.

**Examples:**

-   _How do I fetch entries in a specific locale using Contentstack APIs?_
-   _Review this content type and recommend improvements for structure and usability._
-   _What’s the best way to model a blog content type in Contentstack?_

### Visualization

**Explanation:** Visualization prompts help with reporting and decision support.

**Examples:**

-   _Show a table of entries broken down by locale._
-   _Create a chart comparing published vs. unpublished entries._
