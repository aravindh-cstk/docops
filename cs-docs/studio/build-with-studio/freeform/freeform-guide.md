# Freeform Chapter Guide

## Freeform (optional)

Opt-in feature for pages not tied to a content type: campaigns, landings, one-offs.

## On this chapter

-   [Start here: Chapter overview](/docs/studio/freeform-overview): What Freeform is, when to turn it on, and how it differs from Connected templates.

### Authoring Freeform templates

-   [Freeform templates](/docs/studio/freeform-templates) (Templates not connected to a content type) landing pages, campaigns, "About us", "Contact us".
-   [The Page Data tab](/docs/studio/page-data-tab-for-entry-data-queries-and-external-data): Where you pin Additional Entry Data, Queries, and External Data at the template level.

### Freeform-only right-panel surfaces

The right panel's **Design** tab and per-component **Data** tab only render when Freeform is enabled. Their docs live here because a reader browsing the Composition chapter without Freeform on won't see either of these surfaces.

-   [Design Panel](/docs/studio/style-components-with-the-design-panel): Right-panel styling controls: colours, spacing, typography, borders, shadows, layout, visibility. Backed by design tokens.
-   [Component Data tab](/docs/studio/the-component-data-tab): Per-element Data / Settings tab where authors pin entries and bind fields to selected components.

### Bringing data onto the template

-   [Pinned Entries](/docs/studio/pin-specific-entries-to-a-component): Attach specific entries to a Freeform template so the layout can bind to their fields.
-   [Pinned Queries](/docs/studio/fetch-dynamic-content-with-pinned-queries): Attach a query result so a Repeater inside the template iterates over the matches.
-   [Query Builder](/docs/studio/query-builder): Turn a plain-English prompt or hand-written filter into a saved Pinned Query.
