# Host a Static Site on Launch

## Host a Static Site on Launch

Contentstack Launch allows you to host static sites on Launch by [importing projects from Git repositories](/docs/launch/import-project-using-github/) or by [uploading a zip file](/docs/launch/import-project-using-file-upload/).

By using the steps mentioned in the [Other Frameworks on Launch](/docs/launch/other-frameworks-on-launch#hosting-a-static-site-on-launch) guide, you will be able to host a static site on Launch.
