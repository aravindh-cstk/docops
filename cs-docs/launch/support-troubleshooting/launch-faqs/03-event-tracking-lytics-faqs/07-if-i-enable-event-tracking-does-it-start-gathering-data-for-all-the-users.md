# If I enable Event Tracking, does it start gathering data for all the users?

No. Data collection begins only after users provide explicit consent. To collect user-specific data, you must [configure a custom tag or build a custom consent modal](/docs/launch/event-tracking-in-contentstack-launch#handling-user-consent-optin). When the user accepts, Real-Time User Event Tracking starts for that session.
