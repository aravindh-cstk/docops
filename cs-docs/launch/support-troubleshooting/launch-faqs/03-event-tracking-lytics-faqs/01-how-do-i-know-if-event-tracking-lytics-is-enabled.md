# How do I know if Event Tracking (Lytics) is enabled?

Check your website's HTML for the presence of the Event Tracking <script> tag. If the tag is present, Event Tracking is active. For example: <script async="" src="https://c.lytics.io/api/tag/\*/latest.min.js"></script>
