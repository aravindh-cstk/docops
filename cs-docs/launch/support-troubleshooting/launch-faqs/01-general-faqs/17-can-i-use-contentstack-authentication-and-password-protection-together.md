# Can I use Contentstack Authentication and Password Protection together?

Yes. Both can be enabled for the same Launch environment. When both are enabled, visitors first authenticate through [Contentstack SSO](/docs/launch/contentstack-authentication) and then complete [Password Protection](/docs/launch/password-protection). Access is granted only after both authentication steps are successful.
