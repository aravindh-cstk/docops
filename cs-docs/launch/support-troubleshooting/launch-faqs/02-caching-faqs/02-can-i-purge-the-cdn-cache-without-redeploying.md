# Can I purge the CDN cache without redeploying?

Yes. Go to **Settings** > **Environments** > **Cache** and use the **Cache Revalidation** section to purge by path, cache tags, specific domains, or all domains in the environment, no redeploy needed. You can also do this using the Launch API or an Automations Connector action.
