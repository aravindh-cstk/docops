# What NodeJS Runtime version does Launch support?

Currently, Launch supports Node.js versions 18.x (discontinued as of August 1, 2025), 20.x and 22.x for running website builds during deployment. For more information, please refer to the [supported Node.js versions](/docs/launch/supported-nodejs-versions/).

**Warning**: Support for Node.js version 18 is discontinued for Launch as of August 1, 2025. Update to a supported Node.js version to avoid disruptions in your projects.
