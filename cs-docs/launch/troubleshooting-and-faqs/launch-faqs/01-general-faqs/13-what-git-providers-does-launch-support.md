# What Git providers does Launch support?

Launch currently supports deploying sites via [GitHub](/docs/launch/import-project-using-github/), [BitBucket](/docs/launch/import-a-project-using-bitbucket-cloud), and direct [zip file uploads](/docs/launch/import-project-using-file-upload/). GitLab support will be available shortly.
