# What is the difference between a cached request and an origin request?

A [cached request](https://www.contentstack.com/docs/launch/caching-guide-for-contentstack-launch) is served directly from the CDN because a copy of the content is already stored there. An origin request happens when the CDN does not have the content and fetches it from your application.
