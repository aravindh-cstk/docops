# How is compute time measured?

Compute time is measured in GB-Hours, which combines the memory used and the time it runs. It covers both [build time](https://www.contentstack.com/docs/launch/build-machines-on-launch) and server execution  time. **Note**: The usage analytics section currently displays compute time in Hours. GB-Hours will reflect the full measure as the platform is updated.
