# What happens if a primed URL is no longer needed?

You can use [Automate](/docs/agent-os/what-is-contentstack-agent-os) to purge the cache for the URL and remove the URL from the Cache Priming list. The cache will gradually invalidate outdated content based on your CDN’s expiration policies.
