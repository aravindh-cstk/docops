# How do I enable and configure Cache Priming?

Configure Cache Priming by specifying key URLs in launch.json and enabling the cache priming toggle from the UI. For detailed instructions, refer to the [Cache Priming](/docs/launch/cache-priming#steps-for-execution) document.
