# Does Launch support Next.js ISR (Incremental Static Regeneration)?

No. Launch does not support Next.js ISR or native caching APIs like revalidatePath or revalidateTag. For more details, see [Next.js limitations](/docs/launch/nextjs-on-launch#limitations).
