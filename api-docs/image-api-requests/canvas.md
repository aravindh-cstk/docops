# Set canvas and offset

**API Endpoint**: `/assets/{stack_api_key}/{asset_uid}/{file_uid}/filename.jpg?environment={environment_name}&canvas={width_value},{height_value},offset-x{value},offset-y{value}`

**Method**: `GET`

## Query Parameters

- **canvas** (optional)
  <p>Pass the following values:</p>
<ul>
<li><span data-type="inlineCode">width</span>: Enter the width of the canvas in pixels or percentage.
</li>
<li><span data-type="inlineCode">height</span>: Enter the height of the canvas in pixels or percentage.
</li>
<li><span data-type="inlineCode">offset-x{value}</span>: Enter the horizontal offset of the canvas in percentage.
</li>
<li><span data-type="inlineCode">offset-y{value}</span>: Enter the vertical offset of the canvas in percentage.
</li></ul>
- **environment** (required)
  <p>Enter the environment scoped to your delivery token.</p>
