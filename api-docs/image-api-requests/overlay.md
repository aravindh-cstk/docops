# Overlay base64 image

**API Endpoint**: `/assets/{stack_api_key}/{asset_uid}/{file_uid}/filename.jpg?environment={environment_name}&overlay-base64={relative_URL}`

**Method**: `GET`

## Query Parameters

- **overlay-base64** (optional)
  <p>Specify the relative URL of the base64 image that needs to be set as overlay image.</p>
- **environment** (required)
  <p>Enter the environment scoped to your delivery token.</p>
