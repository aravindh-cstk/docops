# Uninstall an App

<p>The <strong>Uninstall an app</strong> call is used to uninstall an app from your stack or an organization.</p><br>

**API Endpoint**: `/installations/{installation-uid}`

**Method**: `DELETE`

## URL Parameters

- **installation_uid** (required)
  <p>The installation UID of the app.</p>

## Headers

- **authtoken** (required)
  <p>Enter your management token.</p>
- **organization_uid** (required)
  <p>The UID of the organization.</p>
