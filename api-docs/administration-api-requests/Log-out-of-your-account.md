# Log out of your account

<p>The <span data-type="inlineCode">Log out of your account</span> call is used to sign out the user of&nbsp;Contentstack account.</p>

**API Endpoint**: `/user-session`

**Method**: `DELETE`

## Headers

- **authtoken** (required)

## Response

```json
{
	"notice": "You've logged out successfully!"
}
```
