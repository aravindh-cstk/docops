# GenAI

<p>The <span class="code">GenAI</span> request carries prompts, processes them, retrieves relevant data, and returns the processed data.</p><p>To configure the permissions for your application via <a href="/docs/developers/developer-hub/contentstack-oauth" target="_self">OAuth</a>, include the <span class="code">brand-kits:read</span> scope.</p><p>Here’s an example of the Request Body for using GenAI request:</p><pre>{<br />  "prompt": "Enter your prompt",<br />  "knowledge_vault": true,<br />  "voice_profile_uid":"cs************d"<br /> }</pre>

**API Endpoint**: `/v1/genai/`

**Method**: `POST`

## Headers

- **brand_kit_uid** (optional)
  <p>Enter the Brand Kit UID.</p>
- **authtoken** (optional)
  <p>Enter the authtoken.</p>
- **authorization** (optional)
  <p>Enter your OAuth token. Learn more about <a href="/docs/developers/apis/generative-ai-api#authentication" target="_self">Authentication</a>.</p>

## Request Body

```json
{
  "prompt": "Write about Contentstack in 50 words.",
  "knowledge_vault": true,
  "voice_profile_uid": "cs************d"
}
```

Streaming dictionary response
