# Use lanczos2 resize filtering

**API Endpoint**: `/assets/{stack_api_key}/{asset_uid}/{file_uid}/filename.jpg?environment={environment_name}&resize-filter={value}`

**Method**: `GET`

## URL Parameters

- **resize-filter** (optional)
  <p>Enter the filter that needs to be used for resizing the image.</p>

## Query Parameters

- **environment** (required)
  <p>Enter the environment scoped to your delivery token.</p>
