# Delete stack

<p>The <span data-type="inlineCode">Delete stack</span> call is used to delete an existing stack permanently from your Contentstack account.</p>

**API Endpoint**: `/stacks`

**Method**: `DELETE`

## Headers

- **api_key** (required)
- **authtoken** (required)

## Response

```json
{
	"notice": "Stack deleted successfully!"
}
```
