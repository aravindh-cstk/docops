# Delete an app

**API Endpoint**: `/apps/{app_uid}`

**Method**: `DELETE`

## URL Parameters

- **app_uid** (required)
  <p>The UID of the app to be updated.</p>

## Headers

- **authtoken** (required)
  <p>Enter your management token.</p>
- **organization_uid** (required)
  <p>The UID of the organization.</p>
