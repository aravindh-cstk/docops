================================================================================
CRITICAL REMINDERS
================================================================================

✅ Production is READ-ONLY
   - All credentials must have read-only permissions
   - No write operations allowed
   - Enforce in code review process

✅ Published Entries Only
   - All operations filter for status=published
   - Drafts/Scheduled/Archived excluded
   - Sandbox contains no draft entries

✅ Zero Auto-Publishing
   - All imports create DRAFT entries
   - Writers manually publish from Release
   - No automatic publication to Production

✅ Concurrency Protection
   - Only one sync per branch at a time
   - GitHub Actions concurrency groups enforced
   - No simultaneous modifications

✅ Comprehensive Logging
   - Every run logs detailed statistics
   - Every error logged with remediation
   - All retry attempts logged
   - All validations reported (no silent failures)
